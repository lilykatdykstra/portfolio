Automated Greenhouse

Overview

A fully automated miniature greenhouse that uses real-time sensor data to maintain optimal growing conditions for plants — without requiring manual intervention. The system continuously monitors temperature, humidity, and soil moisture, then triggers watering pumps and grow lights automatically based on predefined thresholds.

Built as an end-to-end hardware and software project, the greenhouse combines physical enclosure design, sensor integration, microcontroller programming, and a simple data dashboard for monitoring environmental conditions over time.

Problem Statement

For plant hobbyists, students, and researchers, maintaining a consistent growing environment is time-consuming and easy to get wrong. Inconsistent watering, temperature swings, and poor light schedules are the most common causes of plant stress or death. The goal was to build a low-cost, reliable system that removes guesswork and manual labor from plant care.

  • Manual watering leads to over- or under-watering — the most common plant killer
  • Temperature and humidity fluctuations stress plants and reduce yield
  • Grow light schedules are frequently disrupted by forgetting to toggle switches
  • No easy way to track environmental history for troubleshooting or learning

System Design & Engineering

The system is built around a Raspberry Pi microcontroller connected to three sensor types: a DHT22 temperature/humidity sensor, capacitive soil moisture sensors (one per planting zone), and a light intensity sensor. Outputs include a submersible water pump, a relay-controlled LED grow light strip, and a small cooling fan.

The control logic runs in Python. Each sensor polls at a configurable interval (default: every 5 minutes). When soil moisture falls below threshold, the pump runs for a calculated duration based on pot volume. The grow light follows a programmable day/night schedule. All readings are logged to a CSV and visualized in a browser-based dashboard.

  • Raspberry Pi microcontroller as the main processing unit
  • DHT22 sensor for temperature and humidity monitoring
  • Capacitive soil moisture sensors — more accurate and longer-lasting than resistive
  • 5V submersible mini pump with relay module for automated watering
  • Full-spectrum LED grow light strip on programmable timer relay
  • Python control script with configurable thresholds and intervals
  • CSV data logging + lightweight HTML/JS dashboard for visualization

Build Process

The physical enclosure is a laser-cut acrylic and wood composite structure — transparent sides allow light penetration and visibility while the wooden frame provides structural rigidity. Sensor wiring is routed through channels in the frame to keep the interior clean and accessible.

Software development was iterative — I started with individual sensor test scripts, then integrated them into a unified control loop, and finally added the logging and dashboard layer. Edge cases like sensor read failures and pump stuck-on conditions required adding watchdog logic and manual override buttons.

Outcome & Result

The automated greenhouse successfully maintained a basil and lettuce crop over a 6-week test period with zero manual watering interventions. Sensor data showed the system kept soil moisture within a 5% band of the target value, and temperature remained within ±2°C of the setpoint.

This project taught me how to bridge the gap between hardware and software — particularly how to handle sensor noise, intermittent connections, and the importance of fail-safe design in physical systems. It also reinforced that even "simple" automation requires careful edge-case thinking.
